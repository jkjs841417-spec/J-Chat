
# J-Chat

### Your Own Social Messaging Application

J-Chat is a modern messaging application designed for Android and iOS.

## Features

- Mobile Number Login
- User Profile and Unique ID
- Private Messaging
- Group Chat
- Audio Calling
- Video Calling
- Photo and Video Sharing
- Voice Messages
- QR Code Friend Connect
- Fingerprint, PIN and Pattern Lock
- Secure Messaging

## Technology

- Flutter
- Firebase
- WebRTC
